# 🪑 1·2학년 자습실 좌석배치도

야간 자율학습(정진반)에 참여하는 1·2학년 학생이 **휴대폰으로 오늘 앉을 자리를 고르고**,
감독 선생님은 그 배치도를 보며 **1교시 · 2교시 출결과 메모**를 남기고,
담임 선생님은 **야자 신청 명단**과 **우리 반 출석 기록**을 관리하는 구글 앱스 스크립트 웹앱입니다.
신청하지 않은 날이나 야자를 신청하지 않은 학생도 **「학부모 동의」 를 체크**하면 그날 자리를 고를 수 있고,
감독 · 담임 선생님 화면에 **「미신청 참여」** 로 따로 보입니다.
자습실 구조(114석)는 3학년 자습실 좌석배치도와 같고, 자리 번호는 1·2학년용으로 새로 매겼습니다 —
맨 위 줄 1~12(왼쪽부터) · 왼쪽 줄 13~21 · 가운데 묶음 다섯 개 22~81(묶음마다 왼쪽 줄 위→아래, 이어서 오른쪽 줄) · 오른쪽 줄 82~90 · 아래쪽 91~114.

## 지켜 주는 것

- **학생 개인정보** — 학생 화면에는 남의 학번 · 학년이 가지 않고 이름은 `홍*동` 으로 가려 보냅니다.
- **장난 · 해킹 막기** — 날짜는 서버 시계로만 정해 다른 날 자리를 잡을 수 없습니다. 하루 자리 하나, 바꾸기 3번까지,
  야자 날 · 시간에만. 신청하지 않은 날은 서버가 「학부모 동의」 체크를 다시 확인하고, 체크한 시각을 시트 「기록」 에 남깁니다.
  명단에 있는 학번은 이름이 맞아야 하고(남의 학번으로 처음 등록할 수 없음), 처음 등록은 1분에 40명까지만 받습니다. 학번(숫자 5자리) · 이름(한글 2~5자) · PIN(숫자 4자리) · 메모(100자) 모양을 서버가 다시 검사하고,
  PIN · 비밀번호는 해시로만 저장하며 5번 틀리면 10분 동안 잠급니다. 너무 잦은 요청은 막고, 시트에는 수식이 들어가지 않게 막습니다.
- **30명 동시 접속** — 좌석 현황을 서버 캐시에서 읽고 바뀐 것이 없으면 좌석 목록을 다시 보내지 않습니다.
  저장은 한 번에 하나씩 처리하고, 차례를 기다릴 때는 「새로고침하지 말고 기다려 주세요」 를 띄운 채 저절로 다시 보냅니다.
- 모든 변경은 시트 「변경 기록」 에 누가 · 언제 · 무엇을 남깁니다.

## 설치

앱스 스크립트에 붙여 넣을 파일은 **`src/`** 의 9개입니다(`npm run pack` 을 하면 `dist/appsscript/` 에 같은 파일과 「붙여넣는 순서.md」 가 모입니다).

1. 구글 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**.
2. ⚙️ 프로젝트 설정에서 「`appsscript.json` 매니페스트 파일 표시」를 켜고, `src/` 의 파일을 같은 이름으로 만들어 붙여 넣습니다
   (`Code.gs` · `appsscript.json` · HTML 7개 `index` `teacher` `css` `layout` `core` `student` `tapp` — 이름에 `.html` 은 빼고 적기).
3. 스프레드시트를 새로 고쳐 메뉴 **[자습실 → ① 시트 준비하기]** — 이때 **교사용 비밀번호를 정합니다**(6~30자, 코드에는 남지 않습니다).
4. **배포 → 새 배포 → 웹 앱** (실행: 나 · 액세스: 모든 사용자). 학생에게는 그 주소, 교사는 주소 끝에 `?page=teacher`.
5. 코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전** (새 배포를 만들면 주소가 바뀝니다).

시트 「기록」 의 맨 오른쪽 두 칸 **그날 신청**(신청 · 미신청) · **학부모 동의 확인**(학생이 체크한 시각)은 2026-11-16 에 더한 칸입니다.
그 전에 만든 시트도 다음 기록 때 머리글이 저절로 채워집니다(「① 시트 준비하기」 를 다시 해도 됩니다 — 이미 있는 내용은 그대로 둡니다).
